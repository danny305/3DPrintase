# Local Jmol runtime

Place the full desktop `Jmol.jar` here after downloading and extracting it from the [official Jmol distribution](https://jmol.sourceforge.net/download/). The JAR is ignored by Git and is not packaged or redistributed.

Alternatively, set `THREEDPRINTASE_JMOL_JAR` to its absolute path. See [installation](../../docs/INSTALLATION.md).
