# Bambu Studio settings for printable molecular bonds

These recommendations are based on inspection of `sucralose_71485_PLA_51m33s_thin_bonds.gcode` generated by Bambu Studio 02.08.02.60 with a 0.4 mm nozzle.

## Use a print-safe mesh

Use `--bond-colors uniform` (the pipeline default). The pipeline converts every Jmol bond into one capped, watertight cylinder. Jmol's raw OBJ represents a bond as an open-ended cylinder plus two separate spheres; that raw mesh is retained for provenance but must not be sent to the slicer.

For a robust 0.4 mm-nozzle model:

```sh
3dprintase molecule --cid 71485 --label sucralose \
  --ball-stick \
  --bond-colors uniform
```

The short OBJ filename remains `sucralose_71485.obj`; the settings are recorded by its containing variant folder.

## Recommended Bambu Studio process settings

### Preserve element colors on OBJ import

Keep the OBJ and its matching MTL together. Generated MTL files include the
exact `#FirstTimeUsingMakerLab` compatibility marker recognized by Bambu Studio.
Despite its name, this is used here as a palette-preservation flag: the initial
import uses the explicit material colors instead of automatically clustering
them, which can merge red oxygen with orange phosphorus. All molecule exports
use this flag. It does not change atom identities, coordinates, or mesh geometry.

Re-import the OBJ after updating its MTL; an already imported object or saved
3MF retains its previous filament assignments. In the import dialog keep the
full palette and assign red and orange to separate filaments. Manually reducing
the color count or mapping both to one filament can still combine them.

Implementation references: Bambu Studio's
[MTL parser](https://github.com/bambulab/BambuStudio/blob/master/src/libslic3r/Format/objparser.cpp)
and [initial palette selection](https://github.com/bambulab/BambuStudio/blob/master/src/slic3r/GUI/ObjColorDialog.cpp).

### Process settings

- Nozzle: 0.4 mm
- Layer height: 0.16 mm; use 0.12 mm for the roundest diagonal bonds
- Wall generator: Arachne
- Wall loops: 4
- Detect thin walls: enable if using Classic instead of Arachne
- Outer wall width: 0.42 mm
- Inner wall width: 0.45 mm
- Sparse infill: 15–20%, gyroid or cubic; four walls will make most bonds effectively solid
- Outer wall speed: 30–40 mm/s
- Inner wall speed: 50–60 mm/s
- Overhang wall speed: 20–30 mm/s
- Bridge speed: 20–25 mm/s
- Support: tree/organic, not restricted to critical regions only
- Top support interface layers: 3
- Support interface spacing: 0.25–0.30 mm
- Top Z distance with same-material PLA support: 0.20 mm at 0.16 mm layers
- Support speed: 50–60 mm/s

Rotate the model so the most exposed long bonds are at least about 35–45 degrees above the build plate instead of nearly horizontal. This improves circularity and layer-to-layer continuity and reduces the force needed to remove supports from beneath a bond.

## Small hydrogen sphere receives no automatic support

A hydrogen can be chemically connected and still be skipped by the slicer. In the tested molecular plate, the decisive cause was the **raft**: with raft layers present, Bambu Studio did not route a tree-support branch from the build plate to the isolated hydrogen; setting raft layers to zero restored that branch. Bambu's tree-support implementation treats raft layers as a separate set of layers below the first object layer, so raft geometry changes branch reachability and seeding. This is a slicer decision; changing molecular coordinates or inventing a structural strut is not an appropriate chemistry fix.

Use this sequence:

1. Under **Others > Bed adhesion**, set **Raft layers** to **0**. This is the primary fix for the missing hydrogen support shown in the molecular plate.
2. If more bed adhesion is needed, use an **outer brim** instead of a raft; the brim does not insert extra layers beneath the entire model/support system.
3. In **Process > Support**, enable supports and use **Tree (auto)**.
4. Re-slice and inspect the first layers below the hydrogen. Confirm that a green support/interface branch now originates on the build plate and continues to within the configured top Z gap.

Only if another isolated atom remains unsupported after removing the raft, try the secondary controls: disable **Support critical regions only**, disable **Remove small overhangs**, set **Threshold angle** to 15–20 degrees, disable **Don't support bridges**, and set **Max bridge length** to **0 mm**. Support painting is a last resort, because it cannot repair a tree branch that the raft makes unreachable from the build plate.

For a 0.4 mm nozzle, use a tree tip diameter around 0.8–1.0 mm, 2–3 top interface layers, 0.25–0.30 mm interface spacing, and a 0.16–0.20 mm top Z gap for same-material PLA. A 0.2–0.4 mm support expansion can make very small contacts more reliable, at the cost of slightly harder removal.

If automatic orientation creates many downward-facing hydrogens, rotate the molecule 10–20 degrees and slice again. There is no orientation that eliminates all spherical overhangs, so one or two painted support enforcers are normal for explicit-hydrogen molecular models.

If an AMS is available, a PETG support interface for a PLA model (or the reverse) can permit a near-zero interface gap and much cleaner bond undersides while remaining easy to separate. Verify material compatibility and purge settings before printing.

## What was wrong in the supplied G-code

- Wall generator: Classic
- Wall loops: 2
- Layer height: 0.24 mm
- Thin-wall detection: off
- Sparse infill: 7%
- Support speed: 100 mm/s
- Support limited to critical regions
- Support top Z distance: 0.30 mm
- The first supplied G-code contained 755 width annotations below 0.40 mm. The later color G-code contained 947, including paths as narrow as about 0.086 mm.

The model itself was scaled almost exactly 5× in Bambu Studio: its approximately 11.20 × 7.72 × 7.53 OBJ-unit bounds became approximately 55.98 × 38.63 × 37.44 mm of model toolpaths. Thus a 0.30-unit bond radius becomes 1.5 mm after scaling, or 3.0 mm in diameter. Inspection found the source defect: Jmol's OBJ had 171 intersecting parts and 3,096 open edges. Bambu Studio had to repair those shells while slicing. The repaired OBJ has 85 closed parts (42 atoms plus 43 capped bonds) and zero open edges. A validation slice of the 35%/0.30 Å visual preset at 5× scale and automatic orientation produced no path-width annotation below 0.329 mm.

## Sucralose C–Cl verification

The deposited PubChem conformer contains three single C–Cl bonds measuring 1.774–1.786 Å. In the corrected uniform-bond OBJ, the molecule has exactly 43 capped cylinders for 43 covalent bonds. Each C–Cl connection is therefore represented by one closed cylinder extending into both atom spheres, not an open tube or two abutting colored halves.
